### What this project actually is
The working code lives in a local folder called `permit-stats-online` (`C:\Users\winst\permit-stats-online`, cloned from `https://github.com/winstonoakley/permit-stats-online`). It's a web tool that estimates **lottery odds for backpacking permits**. It covers the Enchantments overnight permit lottery (Alpine Lakes Wilderness, WA); the zone names in the data ("Core," "Snow," "Eightmile," etc.), the up-to-3-choices structure, and the group-size cap of 8 all match that lottery. Users pick a zone, entry date and group size for each choice, and the tool estimates the probability of drawing the permit from historical lottery data. It has nothing to do with hunting, so don't describe it that way. The owner plans to add other permit lotteries later (e.g. Whitney, Half Dome, The Wave).

### Stack
- **Backend**: FastAPI (`app/main.py`), rate-limited with `slowapi`, deployed on Railway via the GitHub integration (51 deploy records 2025-12-02 → 2026-03-16 on the old project). The `ALLOWED_ORIGIN` env var drives CORS.
- **Odds engine**: `app/odds_engine.py` looks up historical draw outcomes from per-year SQLite databases and estimates the success probability for a zone/date/group-size combo, including multi-choice (up to 3 choices) scenarios. The Core zone uses a group-size scaling table (`coregs`), which was re-derived from the data on Sept 7.
- **Data**: `odds_databases/odds_2022.db` through `odds_2026.db`. Analytics v2 database goes on the Railway volume at `/data/analytics.db`.
- **Frontend**: a static `index.html` served by FastAPI, with a heatmap calendar for picking dates.
- **Backtesting**: `backtest.py` checks predictions against actual outcomes (`--target 2025|2026`).
